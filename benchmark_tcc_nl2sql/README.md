# Benchmark do TCC NL2SQL

Contém 30 perguntas (10 simples, 10 intermediárias, 10 complexas), cada uma com SQL de referência.

- `benchmark_30_perguntas_e_sqls.md`: perguntas e SQLs legíveis.
- `perguntas.json`: manifesto estruturado para automação.
- `referencias/Qxx.sql`: SQLs individuais.
- `resultados_esperados.json`: placeholders, a preencher **após executar no PostgreSQL real**.

**Nenhuma consulta foi executada no banco do usuário; SQLs exigem revisão/validação antes de serem considerados gabarito definitivo.**
